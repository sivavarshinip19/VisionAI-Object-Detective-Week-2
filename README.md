# 🔍 VisionAI Object Detective — Week 2

**Detect. Identify. Understand.**

VisionAI Object Detective is a real-time object detection project built using Python, OpenCV, and YOLO. It uses a webcam to detect and highlight objects in live video.

## ✨ Features

- 📷 Real-time webcam detection
- 🎯 Object detection with bounding boxes
- 🤖 YOLO-based computer vision
- 📊 Confidence scores for detected objects
- 🖥️ Live video display using OpenCV

## 🛠️ Technologies Used

- Python
- OpenCV
- Ultralytics YOLO

## 📦 Installation

Install Python, then install the required libraries:

```bash
pip install ultralytics opencv-python
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run:

```bash
python vision_ai.py
```

4. Allow webcam access if prompted.
5. Press **Q** to close the application.

## 🧠 How It Works

1. The webcam captures live video frames.
2. YOLO processes each frame to detect supported objects.
3. OpenCV displays the detected objects with bounding boxes and labels.

## 🚧 Current Limitations

Detection accuracy depends on lighting, object size, camera quality, and the model's supported classes. Custom training may be needed to reliably detect objects not included in the pretrained model.
